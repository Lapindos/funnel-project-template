# Задание 3 · Тег на сайте, источник и отчёты GA4

По презентациям **Тема 04 · Google Analytics 4** и **Тема 05 · Свой сайт,
Vercel и Google Tag** на сайте курса. Работа сдаётся скриншотами из своего
ресурса GA4.

## Что нужно доказать скриншотами

| № | Что доказываем | Где это видно |
|---|---|---|
| 1 | Google Tag установлен на сайт | проверка из инструкции тега: «На вашем сайте обнаружен тег Google» |
| 2 | Тег стоит в коде страницы | исходный код страницы или файл в редакторе, виден `G-XXXXXXXXXX` |
| 3 | Аналитика получает события с сайта | отчёт **Realtime**, событие `page_view` |
| 4 | Источник перехода определяется | переход по своей ссылке с UTM-метками, значение источника в GA4 |
| 5 | На странице «Отчёты» есть статистика | раздел **Отчёты**: пользователи, события, сеансы за период |

Measurement ID возьмите из задания 2. Сайтом служит ваша копия шаблона
[ga4-analytics-lab](https://github.com/MaximBytecamp/ga4-analytics-lab),
опубликованная на Vercel.

Формат: Markdown, скриншоты PNG. На кадрах должны быть видны адрес своего
сайта и свой Measurement ID: по ним проверяется, что работа своя.

Работа уходит в ветку `hw-03` и дальше через запрос на слияние в вашу `main`;
кнопки в VS Code разобраны в [ветках](../docs/git/README.md#5-ветки) и
[публикации Pull Request](../docs/git/README.md#6-ветки-на-github-и-pull-request).

## Как оценивается

| Что проверяется | Вес |
|---|---|
| Тег установлен, проверка пройдена (кадры 1 и 2) | 25% |
| Realtime получает события с сайта (кадр 3) | 20% |
| Источник перехода определился по UTM-ссылке (кадр 4) | 25% |
| Страница «Отчёты» со статистикой (кадр 5) | 20% |
| Бланк заполнен, адреса и идентификаторы совпадают с кадрами | 10% |

Кадры из чужого ресурса, демонстрационные и с замазанным Measurement ID
не принимаются: по идентификатору сверяется, что аналитика ваша.

## Если события не появляются

| Признак | Что проверить |
|---|---|
| Тег не обнаружен | тег стоит перед `</head>`, сайт опубликован, публикация в статусе READY |
| События двоятся | тег вставлен дважды на одну страницу |
| Realtime пуст | сайт открыт по публичному адресу или это файл с диска |
| Источник `(not set)` | переход сделан по ссылке с `utm_source`, `utm_medium`, `utm_campaign` |
| В «Отчётах» пусто | данные там появляются не сразу: в Realtime сразу, в отчётах в течение суток |
