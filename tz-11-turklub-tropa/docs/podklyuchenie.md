# Как подключить GA4 и таблицу

Сайт уже вызывает тег и шлёт заявку так, как это устроено в темах 4–7 курса. Ниже только ваши действия в аккаунтах. Код менять больше не нужно, кроме трёх значений.

Опора на курс:

- тема 4 — ресурс, поток, Measurement ID;
- тема 5 — тег в `<head>` и публикация на Vercel;
- тема 6 — свои события, DebugView, пользовательские параметры, ключевые события;
- тема 7 — лист `leads`, `doPost`, форма;
- тема 9 — ManyChat;
- темы 10 и 10.2 — отчёты GA4 и DataLens.

Отличие от учебной формы темы 7, его спросят на защите: учебная форма отправляет обычный POST и вызывает `generate_lead` в момент нажатия кнопки. Здесь форма уходит через `fetch` без перезагрузки, а `generate_lead` вызывается только после ответа `{"ok": true}`. Так написано в разделе 4.3 ТЗ. Метки читаются из адреса и кладутся в `sessionStorage`, чтобы не потеряться по дороге до `contacts.html`.

## 1. Сайт на Vercel

1. Залейте эту папку в ветку, с которой деплоит Vercel. Для приёмки по ТЗ это `main`.
2. В Vercel: Add New → Project → репозиторий. Framework Preset: Other. Если код лежит внутри `funnel-project`, Root Directory: `tz-11-turklub-tropa`.
3. Deploy. После каждого push в продовую ветку сайт обновляется сам.
4. Адрес вида `https://<имя>.vercel.app` впишите в README и в формулу листа `utm`, если он отличается от `https://tz-11-turklub-tropa.vercel.app`.

## 2. Ресурс GA4 «ТРОПА — сайт»

Не используйте ресурс домашних работ. В коде сейчас стоит его идентификатор `G-YQM8LSJ9F7`, чтобы тег уже был на месте. Его надо заменить.

1. [analytics.google.com](https://analytics.google.com) → Администратор → Создать ресурс.
2. Название: `ТРОПА — сайт`. Часовой пояс: Москва, `(GMT+03:00)`. Валюта: российский рубль.
3. Платформа: Web. Адрес потока — адрес Vercel из шага 1.
4. В настройках потока включите расширенную статистику (Enhanced measurement), в том числе взаимодействия с формами. Тогда сами приедут `page_view`, `scroll`, `click`, `file_download`, `form_start`, `form_submit`.
5. Скопируйте Measurement ID, он начинается с `G-`.
6. Во всех девяти HTML (`index.html`, `trips.html`, `calendar.html`, `guides.html`, `gear.html`, `contacts.html`, `thanks.html`, `privacy.html`, `404.html`) замените `G-YQM8LSJ9F7` на новый ID. Он стоит дважды: в адресе `gtag/js?id=` и в `gtag('config', …)`.
7. Закоммитьте и дождитесь Deployment Ready.
8. Проверка, как в теме 5: откройте сайт по ссылке с метками, в Realtime у визита источник равен `utm_source`. В исходном коде трёх любых страниц в `<head>` виден новый ID. Это испытание И-02.

### Пользовательские параметры

Администратор → Отображение данных → Пользовательские определения → Создать специальный параметр. Область: Событие. Создайте семь штук, имя параметра совпадает с тем, что шлёт сайт:

| Параметр | Событие |
|---|---|
| `button_name` | `cta_click` |
| `page_section` | `cta_click`, `social_click` |
| `difficulty` | `trip_filter`, `trip_view` |
| `trip_id` | `trip_view`, `date_select` |
| `seats_left` | `date_select` |
| `lead_trip_id` | `generate_lead` |
| `messenger` | `messenger_click` |

### Ключевые события

Администратор → События. Отметьте ключевыми только `generate_lead`, `contact_click`, `messenger_click`. Других ключевых быть не должно.

### DebugView

Поставьте расширение Google Analytics Debugger или на время проверки добавьте в `gtag('config', 'G-…', { debug_mode: true })`. Снимите кадр каждого события из таблицы 4.2 ТЗ в `screens/ga4/` под именем события, например `trip_filter.png`. Параметры на кадре раскрыты. Перед сдачей `debug_mode: true` из кода уберите.

## 3. Таблица «Tropa — Bookings»

Так же, как в теме 7, только столбцы шире: в брони есть телефон, маршрут, дата и число участников.

1. Создайте таблицу с названием `Tropa — Bookings`.
2. Из адреса `https://docs.google.com/spreadsheets/d/ЭТОТ_КУСОК/edit` скопируйте ID.
3. Вставьте его в `apps-script/Code.gs` вместо `PASTE_YOUR_SPREADSHEET_ID`.
4. В таблице: Расширения → Apps Script. Вставьте весь `Code.gs`, сохраните.
5. В списке функций выберите `setupWorkbook` и нажмите «Выполнить». Разрешите доступ. Функция создаст лист `leads` (заголовки, закреплённая строка, списки `status` и `trip_id`, подсветка пустых обязательных ячеек и повтора `request_id`) и лист `utm` с формулой полной ссылки.
6. Развернуть → Новое развёртывание → Тип: веб-приложение. Выполнять от имени: меня. У кого есть доступ: все. Скопируйте URL, он заканчивается на `/exec`.
7. В `contacts.html` замените `REPLACE_WITH_DEPLOYMENT_ID` в `action` формы на этот URL. Закоммитьте.
8. Откройте доступ на просмотр для e-mail преподавателя. Публичную ссылку на таблицу с телефонами не делайте.
9. После правки `Code.gs` нужно новое развёртывание (Управление развёртываниями → карандаш → Новая версия). Старый `/exec` иначе останется на старом коде.

Проверка:

- заявка без меток пишет `direct` / `none` / `not_set` / `not_set` и статус `new`;
- заявка по ссылке из реестра пишет метки этой строки;
- пустой телефон и телефон `123` форму не отправляют, у поля текст ошибки, в DebugView есть `form_error`;
- повтор того же `request_id` не создаёт вторую строку, приёмник возвращает `duplicate_request_id`;
- одну тестовую заявку проведите `new → contacted → prepaid → went`, другую закройте `lost`.

`created_at` и `status = new` ставит скрипт. Статус из браузера игнорируется.

Если `fetch` не может прочитать JSON, откройте URL `/exec` в браузере: пустой GET должен показать ошибку скрипта, это нормально, `doGet` нет. POST с сайта должен вернуть JSON. Частая причина пустого ответа — доступ веб-приложения не «все» или после правки не создана новая версия.

## 4. UTM, короткие ссылки, QR

Реестр уже лежит в `docs/utm.csv` и заполняется на лист `utm` функцией `setupWorkbook`. Полная ссылка собирается формулой в столбце J, руками её не набирайте. Пять меток: `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`. Якорь, если он есть, стоит после меток. Пример U-03:

```text
https://<сайт>.vercel.app/trips.html?utm_source=instagram&utm_medium=social&utm_campaign=beginners_dec_2026&utm_content=reel_tent_01_easy&utm_term=winter#easy
```

Короткие ссылки нужны для ВКонтакте и Telegram: строки U-05, U-06, U-07, U-08. Сервис `vk.cc` или `clck.ru`. После перехода по короткой ссылке в адресе сайта должны остаться все пять меток. Снимок адресной строки — в `screens/utm/`.

QR для U-12 уже собран: `docs/qr-u-12.png`, афиша A4 — `docs/afisha.pdf`. Если адрес Vercel другой, пересоберите QR на новую полную ссылку.

В `utm_source` строк U-10 и U-11 стоят заглушки `partner_one` и `partner_two`. Перед публикацией замените их на ники двух одногруппников латиницей, строчными буквами, без дефиса.

Публикации — отдельные страницы компании, не личный аккаунт. Минимум четыре сети: Instagram, ВКонтакте, Telegram, YouTube. Проверка ссылки — клик из самой публикации, не вставка в адресную строку. Для U-01, U-05, U-07, U-09, U-10, U-11, U-12 отправьте заявку с именем `Тест U-05` (свой номер). Через 24–48 часов в Traffic acquisition при группировке Session source / medium должно быть не меньше шести пар.

## 5. ManyChat

Аккаунт Instagram — профессиональный, отдельный для проекта. Reel: «Ночёвка в палатке при −15 °C». Автоматизация `IG · Winter Trips 2026 · Tent Reel`, режим Live.

Ветка 1. Триггер: комментарий к этому Reel, слово `СНАРЯГА`. Ответ в комментариях — один из трёх, ManyChat выбирает случайно:

- «Отправили чек-лист в личные сообщения 🏔»
- «Проверь директ — там список снаряжения»
- «Готово! Чек-лист и промокод уже в сообщениях»

Direct: «Привет! Это «Тропа». Держи чек-лист «Что взять в зимний поход» и калькулятор аренды — если чего-то нет, дадим.» Кнопка «Открыть чек-лист» → полная ссылка U-02.

Ветка 2. Слово `НОВИЧОК`. Текст: «Три зимних маршрута, которые проходят без опыта, — по кнопке ниже.» Кнопка «Маршруты для новичков» → полная ссылка U-03.

Проверка со второго аккаунта, пауза между комментариями не меньше 2 минут. Кадры — в `screens/instagram/`.

## 6. Отчёты и DataLens

Отчёты стройте не раньше чем через 24–48 часов после проверок. Период — от первой проверки до дня сдачи. Список кадров и файлов — в [chto-snyat.md](chto-snyat.md). Числа в `docs/report.md` вписываете только из этих кадров.

Data Studio из России недоступен, дашборд — в Yandex DataLens, как в теме 10.2.

1. Выгрузку свободной формы положите в ту же Google Таблицу, листы `ga4_traffic` и `ga4_leads`, без служебных строк и без «Общего итога».
2. Значения `(direct)` и `(not set)` приведите к `direct` и `not_set`, как их пишет форма.
3. Дашборд `ТРОПА — winter_trips_2026`, три вкладки: «Трафик», «Заявки», «Кампании». На каждой закреплён селектор периода, и он меняет все виджеты вкладки.
4. Имена, телефоны и e-mail в датасет заявок не выводите.
5. Доступ «Просмотр» для преподавателя. Публичную ссылку не создавайте.

На вкладке «Кампании» связь только по source, campaign и дате. В таблице: сеансы и `generate_lead` из GA4, заявки из листа `leads`, заявки в статусе `went`. «Заявок на 100 сеансов» считается в записке, не обязательно отдельным виджетом.
