# Задание 5 · Контролируемая таблица заявок

По презентации **Тема 07 · Контролируемая таблица заявок** на сайте курса.
Работа сдаётся скриншотами из своей таблицы Google, своего Apps Script
и своего сайта.

**Презентация:** https://algorthimization-course-vvodnoe.vercel.app/op03-informacionnye-tehnologii/lessons/07-google-sheets-leads/index.html

**Материалы и код:** https://algorthimization-course-vvodnoe.vercel.app/op03-informacionnye-tehnologii/lessons/07-google-sheets-leads/materials.html

**Изучили:** чем событие GA4 отличается от заявки; таблицу с девятью
столбцами, списком статусов и подсветкой ошибок; приёмник Apps Script
с функцией `doPost(e)` и публикацию его как веб-приложения; форму сайта,
которая отправляет заявку в приёмник вместе с UTM-метками; зачем нужен
`request_id` и почему время и статус `new` ставит сервер.

## Что сделать

Пройти практику темы 7 на своём сайте: том же, что в заданиях 3 и 4.
Новый сайт, новый проект Vercel и новый поток GA4 не создаются.

1. Таблица `GA4 Analytics Lab — Leads`, лист `leads`, девять заголовков,
   закреплённая первая строка, список статусов и два правила подсветки.
2. Приёмник: в Apps Script вставлен `Code.gs` из материалов, в нём ID
   вашей таблицы, проект опубликован как Web app.
3. Форма в `contacts.html` заменена фрагментом из материалов, в `action`
   стоит ваш адрес `/exec`, обработчик формы в `js/script.js` заменён
   новым. Изменения опубликованы: Deployment в статусе **Ready**.
4. Две тестовые заявки: одна без меток, вторая по ссылке с метками.
5. Проверки: пустое обязательное поле, дубль `request_id`, неверный статус
   и смена статуса через список.

Код целиком лежит в материалах: `Code.gs`, `form.html`, `lead-form.js`.
Писать его самому не нужно, но нужно уметь объяснить, что делает каждая
часть: разбор по шагам есть в презентации.

## Ссылка для второй заявки

## Доступ к таблице

Ссылку на таблицу вписываете в бланк, а доступ открываете только
преподавателю: **Настройки доступа → добавить адрес преподавателя →
Читатель**. Доступ «всем, у кого есть ссылка» не открывайте: в таблицу
пишет форма с публичного сайта.

## Как оценивается

| Что проверяется | Вес |
|---|---|
| Таблица: заголовки, закрепление, список статусов, правила (кадр 1) | 15% |
| Приёмник опубликован, форма отправляет в него (кадры 2–4) | 25% |
| Обе заявки записались, метки на месте (кадры 5 и 6) | 25% |
| `generate_lead` виден в аналитике (кадр 7) | 10% |
| Дубль и неверный статус пойманы (кадры 8 и 9) | 15% |
| Бланк заполнен, `request_id` и адреса совпадают с кадрами | 10% |

## Если не работает

| Признак | Что проверить |
|---|---|
| Форма не отправляется | остался старый обработчик с `preventDefault`, в `action` нет адреса `/exec`, не заполнены обязательные поля |
| Строка не появилась | адрес оканчивается на `/exec`, доступ Web app, ID таблицы, лист называется ровно `leads`, порядок заголовков; журнал **Executions** в Apps Script |
| Код поправлен, а поведение прежнее | сохранить мало: нужна новая версия развёртывания Apps Script |
| В строке `direct`, хотя ссылка с метками | ссылка вела на главную, а не сразу на `contacts.html` |
| Строка есть, а `generate_lead` нет | тег на странице, блокировщик рекламы, выбранный поток данных. Заявку ради события повторно не отправляйте |
