## Требования к оформлению

| Требование | Как проверяется |
|---|---|
| Шапка заполнена целиком | все шесть полей таблицы выше |
| Формат файла | Markdown, `.md`, имя из бланка работы |
| Расположение | папка своего задания, не корень репозитория |
| Скриншоты | PNG, в папке `screens/` рядом с бланком |
| Имена скриншотов | `01-что-на-кадре.png`, нумерация по порядку упоминания |
| Ссылки на скриншоты | `![подпись](screens/01-что-на-кадре.png)` в тексте бланка |
| Пустые заготовки | удалены, незаполненных строк таблиц не остаётся |
| Ссылки на источники | полным адресом, рабочие на момент сдачи |

## Что считается несделанной работой

- Текст без источников, ссылок и скриншотов.
- Скриншоты без бланка или бланк без скриншотов.
- Придуманные показатели компаний. Если показатели не опубликованы,
  так и напишите: «точные показатели в открытом источнике не приведены».
- ИИ можно использовать для поиска идей, структуры и формулировок.
  Источником ИИ не считается: каждый факт, цифру и кейс сопровождайте
  ссылкой на исходный материал.
