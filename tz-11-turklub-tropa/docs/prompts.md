# Запросы к нейросети

Инструмент: Cursor, модель Grok 4.7. Сайт статический: HTML, CSS и JavaScript без сборки.

## 1. Структура сайта

Запрос: прочитать ТЗ-11 «Тропа» и шаблон курсовой, собрать сайт строго по разделам 2 и 3: восемь страниц и `404.html`, порядок блоков из приложения А, фирменные цвета и шрифты, события из раздела 4.

Получилось: каркас страниц, шапка, подвал, меню с текущим пунктом, данные маршрутов в `js/data.js`.

Исправлено вручную по смыслу ТЗ: километраж и набор высоты не выдуманы и на карточки не поставлены. Имена инструкторов, которых нет в ТЗ, не придуманы: на карточках роли «инструктор группы» и «второй инструктор группы». Скидка по промокоду SNOW300 в ТЗ не задана, на сайте есть только код.

## 2. Главная

Запрос: первый экран «Зимние походы: 6 маршрутов», подбор по сложности и длительности, четыре ближайших выезда, три карточки инструкторов, блок безопасности, подвал с соцсетями.

Получилось: `index.html` с числами из письма директора: 2 000, 16, 58, 6.

Исправлено: убраны служебные фразы про «заказчик не указал» — на сайте остались только сведения из раздела 2.

## 3. Маршруты

Запрос: фильтр сложности и дней, шесть карточек, кнопка «Забронировать», якорь `#easy` для ссылки U-03.

Получилось: `trips.html`. При открытии `trips.html#easy` фильтр сам ставится в «Легко».

## 4. Календарь

Запрос: декабрь 2026 и январь 2027 из массива в JavaScript, выезд без мест с подписью «Мест нет» и ссылкой на ближайшую другую дату того же маршрута, место сбора на карте.

Получилось: `calendar.html` и отрисовка в `js/ui.js`. Даты без мест: 13.12 и 20.12 у «Ледяных водопадов» нет, есть 06.12 и 20.12; у снегоступов 19.12 без мест, следующая дата 09.01; плато 26.12 без мест, следующая 17.01; траверс 22.01 без мест, предыдущая 15.01.

## 5. Инструкторы, снаряжение, бронь, спасибо, политика, 404

Запрос: отдельные страницы по таблице 3.2. Чек-лист, калькулятор аренды по ценам раздела 2, скачивание PDF, промокод SNOW300. Форма без вопросов о здоровье, два обязательных флажка, оба сняты. На странице спасибо — номер брони и предоплата 30%. Политика по 152-ФЗ.

Получилось: `guides.html`, `gear.html`, `contacts.html`, `thanks.html`, `privacy.html`, `404.html`, файл `files/checklist-winter.pdf`.

Исправлено: ссылка на политику вынесена из подписи флажка, чтобы клик по ней не ставил галочку. Калькулятор показывает строку вида `(500 + 150) × 2 = 1 300 ₽`.

## 6. Аналитика

Запрос: все вызовы `gtag('event')` в одном `js/analytics.js`, кнопки описаны атрибутами `data-event`, как в разделе 4.3. Тег в `<head>` каждой страницы, включая 404, по образцу темы 5.

Получилось: обработчик клика по `[data-event]` и функция `TropaAnalytics.send` для событий, которые рождаются в скрипте: фильтр, календарь, чек-лист, аренда, ошибка формы, заявка.

Исправлено: числовые параметры (`rental_price`, `seats_left`, `participants` и другие) уходят числом, а не строкой, чтобы в DebugView у испытания И-13 было `rental_price = 1300`.

Получилось: `apps-script/Code.gs` и `js/form.js`. Адрес приёмника лежит в `action` формы, как URL в учебной форме темы 7. Метки сохраняются в `sessionStorage`.

Исправлено относительно темы 7: учебный `generate_lead` в момент клика убран, иначе событие уходило бы до ответа таблицы. Добавлена функция `setupWorkbook`, которая готовит листы. Её запускаете вы.
