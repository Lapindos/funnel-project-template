# Источники изображений

Фотографий реальных мест в ТЗ нет, чужие снимки не используются. Картинки маршрутов, места сбора, значок и картинка Open Graph нарисованы для этого проекта: плоские плакаты в цветах клуба, синий лёд `#2B6F8F` и оранжевый `#F08A24`. Это не фотографии Седой горы и не кадры чужого похода.

| Файл | Что это | Размер |
|---|---|---|
| `img/icefalls.jpg` | плакат «Ледяные водопады» | JPEG, меньше 300 КБ |
| `img/snowshoes.jpg` | плакат «Снегоступы для начинающих» | JPEG, меньше 300 КБ |
| `img/sunrise.jpg` | плакат «Рассвет на Седой горе» | JPEG, меньше 300 КБ |

| `img/traverse.jpg` | плакат «Лыжный траверс» | JPEG, меньше 300 КБ |
| `img/newyear.jpg` | плакат «Новогодняя изба» | JPEG, меньше 300 КБ |
| `img/meeting.jpg` | схема сбора на вокзале | JPEG, меньше 300 КБ |

Шрифты на сайте: Russo One и Inter с Google Fonts. В PDF презентации — Inter, он есть локально и поддерживает кириллицу.
